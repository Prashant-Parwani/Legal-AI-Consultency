# Lexora — AI Legal Consultancy Landing Page

## Technology
- HTML5
- Tailwind CSS
- Tailwind Typography

## Project
Responsive landing page for an AI-powered legal consultancy platform designed for startups and corporations.

## Purpose
Created as part of Lab Exercise 1 to demonstrate semantic HTML5, responsive Tailwind CSS design, Typography plugin usage, and GitHub collaboration.

## How to Run
Open index.html in Google Chrome.
